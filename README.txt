GOALPULSE - Script package

1) Upload script.js into the SAME folder as index.html in your GitHub repository.
2) Open index.html and add this line just before </body>:
   <script src="./script.js" defer></script>
3) If index.html already has an older GoalPulse script block or another script.js include, remove/replace the old GoalPulse code to avoid running two versions at once.
4) Commit changes, wait for GitHub Pages to redeploy, then hard refresh with Ctrl+F5.

Important: This ZIP contains the JavaScript file and instructions, not the full website. The page's HTML must contain the element IDs expected by script.js.
